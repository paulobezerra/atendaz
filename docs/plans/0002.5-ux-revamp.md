comportamento**. Esta fase é **apresentação apenas** — não altera regra de negócio, modelo
nem contrato de API. As partes pesadas foram fatiadas:

**lucide-react**, **react-hook-form** + **@hookform/resolvers**, **@tanstack/react-query**,
**@tanstack/react-table**, **react-imask**.
