# Planos de Execução (`docs/plans`)

Esta pasta contém os planos de execução detalhados para cada funcionalidade (F{ID}).

## Regras
- Cada arquivo deve ser nomeado como `{ID}-{slug}.md`.
- O plano deve ser criado pelo comando `/plan {ID}` e validado pelo usuário antes da execução pelo comando `/code {ID}`.
- O plano é um contrato de implementação: o que está no plano é o que será codado.
